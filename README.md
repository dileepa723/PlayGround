# PlayGround — San Andreas: Neon State

A fan-made, browser-based open-world driving tribute to **GTA: San Andreas**, reimagined as a neon-lit 2026 West Coast city.

Run the courier circuit, collect data shards, dodge traffic, and outrun the APEX patrol in seven modern electric vehicles — or park the car and explore on foot.

## Run

```bash
npm install
npm run dev      # http://localhost:3002
npm run build    # production build in dist/
```

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move / steer | `WASD` or arrow keys | left joystick |
| Boost / sprint | `Shift` | ⚡ button |
| Handbrake (drift) | `Space` | `HB` button |
| Enter / exit vehicle | `E` | `E` button |
| Look around | drag the mouse | drag the canvas |
| Zoom camera | mouse wheel | — |
| Music on/off | `M` | speaker button |

## Features

- 25-block open city with boulevards, sidewalks, parks, beach, pier, Ferris wheel, skyline, and a neon showroom plaza.
- Seven modern EVs with distinct handling, plus an APEX police interceptor.
- Arcade driving with acceleration, drift, boost battery, headlights, collisions, and vehicle damage.
- On-foot movement with sprint and jump, plus a rideable MANTIS R superbike.
- Traffic and pedestrian AI, wanted stars, police pursuit, busted/wasted respawns.
- Courier delivery missions, collectible data shards, cash rewards, and a live minimap.
- Procedural synthwave soundtrack, engine audio, and SFX — no external assets.
- Responsive desktop and mobile UI with touch controls and safe-area support.

Built with Vite and Three.js. All geometry, textures, and audio are generated at runtime.
