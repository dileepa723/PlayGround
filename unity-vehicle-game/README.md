# Unity Vehicle Game — Arcade Lap Racer

A complete, drop-in arcade racing game for Unity 3D. Drive a hand-tuned
Rigidbody car around an oval track, pass the gates in order, collect coins,
boost, drift, and beat your best lap time. Everything (track, car, HUD,
camera) is generated by a single editor menu command — no assets required.

**Genre:** 3D arcade racing · **Physics:** custom rigidbody controller
(stable, keyboard-friendly) · **Requirements:** Unity **2021.3 LTS or newer**
(Built-in or URP render pipeline).

---

## Quick start

1. Create a new Unity project (any 3D template).
2. Copy the `Assets` folder from this directory into your project (or copy
   `Assets/Scripts` if the project already has its own assets).
3. Wait for the domain reload, then in the menu bar pick:

   **Tools → Vehicle Game → Build Demo Scene**

4. Press **Play**. 3… 2… 1… GO!

The builder creates and saves `Assets/Scenes/Vehicle Demo.unity` and adds it
to Build Settings. You can re-run the menu command any time to regenerate the
scene from scratch.

> **URP note:** the builder tries the Standard shader first and falls back to
> URP/Lit automatically. If anything renders pink, select the generated
> materials and point them at a URP Lit material.

## Controls

| Action | Keys |
|---|---|
| Accelerate / Brake / Reverse | `W`/`↑`, `S`/`↓` |
| Steer | `A`/`D` or `←`/`→` |
| Boost | `Shift` (consumes the boost bar) |
| Drift | `Space` (hold while steering) |
| Reset car | `R` (also respawns automatically when falling off) |

## Manual setup (without the scene builder)

If you'd rather wire it yourself:

1. **Ground:** any plane/terrain that a raycast can hit (default layer mask = everything).
2. **Car:** create an empty `Player` GameObject with a `Rigidbody` (mass ~1200,
   interpolation Interpolate) and a `BoxCollider` covering the body. Add
   `VehicleController` to the root — it configures the rigidbody at runtime.
3. **Wheels (optional):** add child cylinder transforms and drag them into
   `frontWheels` / `rearWheels`. Rotate them so the cylinder axis is along the
   car's X axis (local rotation `(0, 0, 90)`), remove their colliders.
4. **Camera:** add `CameraFollow` to the Main Camera; set `target` = car root.
5. **Gates:** for each gate, an empty GameObject with an *isTrigger* collider
   and the `Checkpoint` component; set `Order` 0, 1, 2, … and tick `IsFinish`
   on the last one. Lap completes on the finish gate.
6. **Coins:** small mesh + isTrigger collider + `CoinCollectible`.
7. **Manager:** empty GameObject with `RaceManager` (set `Total Laps`).
8. **HUD:** a Screen Space canvas with any of the `GameHUD` text/image fields
   assigned — every field is optional and auto-updates.

## Tuning guide (VehicleController inspector)

| Field | Effect |
|---|---|
| `Max Speed` / `Boost Max Speed` | Top speed, km/h (throttle cap) |
| `Accel Rate` | How fast the engine builds speed (higher = launch harder) |
| `Brake Rate` | Stopping power |
| `Steer Strength` | Full-lock turn rate (deg/s); auto-reduced at rest and inverted while reversing |
| `Lateral Grip` | Higher = tighter corners; lower = slidey |
| `Drift Lateral Grip` / `Drift Steer Multiplier` | How loose and twitchy drifting feels |
| `Downforce` | Higher = car hugs the ground/ramps |
| `Boost Capacity / Burn / Regen` | Seconds of boost, drain rate, refill rate |
| `Fall Height` | Below this Y the car respawns; also `Reset Key` |

Race rules live on the `RaceManager` (`Total Laps`, `Countdown Seconds`);
best time persists per-project via `PlayerPrefs`.

## Troubleshooting

- **Pink track/objects** → render pipeline mismatch; reassign materials to your pipeline's Lit shader.
- **HUD text missing** → built-in font lookup failed; assign a font to the HUD `Text` components manually.
- **Car spins out of control** → raise `Lateral Grip`, or lower `Steer Strength`.
- **Gate not counting** → the car root needs a (non-trigger) collider, and gates must be passed in ascending `Order`.
- **Wheels roll backwards** → tick `Invert Wheel Spin` on the controller.
- **Fell through the world** → hit `R`; the car respawns at its spawn point.
